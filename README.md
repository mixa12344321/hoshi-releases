# Hoshi for Windows

Публичные сборки Hoshi для Windows 10/11 x64. GitHub-аккаунт для скачивания не нужен.

[Скачать последнюю версию](https://github.com/mixa12344321/hoshi-releases/releases/latest)

- `nsis.exe` — установщик. `portable.exe` — запуск без установки.
- Каталог аниме, разные озвучки, собственный плеер и личная библиотека.
- Начиная с 0.4.0: **Настройки → Обновления Hoshi**. Новые выпуски проверяются автоматически; скачивание и установка — по кнопке.
- **Чат**: введите имя → создайте комнату → скопируйте приглашение другу. На втором ПК: имя → приглашение → подключиться. Radmin/Hamachi не нужны. ПК создателя должен быть включён, Hoshi открыт.
- Интернет-связь чата — бета на публичных WSS-ретрансляторах EMQX / HiveMQ; есть отдельный режим локальной сети. Связь и шифрование встроены в Hoshi; отдельный сетевой клиент не устанавливается.
- Версию 0.3.0 нужно один раз обновить установщиком последней версии. Библиотека сохраняется. В portable новый EXE заменяется вручную.

Этот репозиторий содержит только выпуски и подписанный файл обновления `hoshi-update.json`. Исходники находятся в отдельном закрытом репозитории. Сборки пока не имеют сертификата издателя Windows; Hoshi отдельно проверяет цифровую подпись описания обновления и целостность файла.
